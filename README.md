# Sistema de Gestão Familiar - Engels

**Autor**: Engels Eugenio Mateus  
**Disciplina**: Programação Web  
**Ano**: 2026

## Descrição
Sistema web desenvolvido em PHP + MySQL para gestão de pessoas e casamentos familiares. 

## Funcionalidades
- Cadastro de pessoas
- Registo de casamentos com validação de idade mínima 18 anos
- Árvore genealógica
- Relatórios

## Tecnologias
- PHP 8.x
- MySQL/MariaDB
- HTML5, CSS3, Bootstrap
- XAMPP

## Como usar
1. Importar `banco.sql` no phpMyAdmin
2. Configurar `conexao.php` com banco de dados
3. Acessar `localhost/Gestao_familiar_Engels`
